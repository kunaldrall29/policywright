Policywright turns a Stellar/Soroban transaction a user has already performed
(or simulated) into the least-privilege
[OpenZeppelin smart-account](https://docs.openzeppelin.com/stellar-contracts/accounts/smart-account)
authorization that permits exactly that flow — context rules plus the minimum
policy set — then dry-runs it and reconciles against chain (or a fixture)
before a **human-signed, testnet-only** install. Built in response to the SCF
'OZ accounts policy builder' RFP (Q2 2026), funded in round SCF #44 as the
awarded submission 'Record-to-Policy MCP + Agent skill.' Proof today: live
testnet smart account
[`CAXBVHXP…`](https://stellar.expert/explorer/testnet/contract/CAXBVHXP4QCWFNWW223JC6DAZHRXDUS5NDRSZMFSEYKCX4C3C5U4ERXT)
with installed rules, frequency policy
[`CDSVPSTS…`](https://stellar.expert/explorer/testnet/contract/CDSVPSTSKMJ2EEP4FOJ3NNIJZY5DKVA3VV5BM453AOYIWCLD4NMG2ZPP),
committed live artefacts under
[`examples/live/`](https://github.com/kunal-drall/policywright/tree/main/examples/live),
stdio MCP
([`docs/mcp-server.md`](https://github.com/kunal-drall/policywright/blob/main/docs/mcp-server.md)),
and the Claude skill

## The pipeline

1. **Record** — capture a transaction as a normalised `RecordedTx` (fixture,
   live RPC hashes, or saved `simulateTransaction`).
2. **Synthesize / emit** — least-privilege `SmartAccountSpec` → `spec.json`,
   installable `context-rule.json`, summary, and stamped illustrative Rust.
3. **Simulate** — dry-run permit / deny / flag before anything is installed.
4. **Verify** — diff emitted rules against an on-chain snapshot or live SA.
5. **Install (CLI, human-signed, testnet only)** — not an MCP tool; Freighter
   preferred, local-signer fallback labeled —
   [Smart-account install](/guides/smart-account-install/).

Agents reach steps 1–4 via the [MCP server](/reference/mcp-tools/) and
[Claude skill](/reference/claude-skill/). See [Architecture](/architecture/)
and [Getting Started](/getting-started/).

## Prior art

Policywright extends
[kalepail/pollywallet](https://github.com/kalepail/pollywallet) by deriving
least-privilege authorization from a transaction the user already performed,
plus an offline dry-run before install. Open source under the
[MIT license](https://github.com/kunal-drall/policywright/blob/main/LICENSE).
