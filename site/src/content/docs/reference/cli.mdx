## Commands

| Command | What it does |
| ------- | ------------ |
| `npm run demo` | End-to-end pipeline + dry-run self-check (offline) |
| `npm run cli -- synth` | Synthesize from fixture or `--input <recorded.json>` |
| `npm run cli -- simulate` | Dry-run scenarios + report |
| `npm run record -- <txHash>…` | Fetch/merge live txs as one `RecordedTx` |
| `npm run record -- --from-simulation <file>` | Ingest saved `simulateTransaction` exchange |
| `npm run cli -- verify` | Diff emitted context-rule vs snapshot or live `--smart-account` |
| `npm run cli -- account:create` | Deploy OZ smart account on **testnet** |
| `npm run cli -- install` | `add_context_rule` from emitted JSON (**testnet**) |
| `npm run mcp` | stdio MCP — four tools; **no install** |
| `npm run cli -- help` | Usage |

Install details: [Smart-account install](/guides/smart-account-install/).

## Synthesis flags (`synth` and `simulate`)

| Flag | Default | Meaning |
| ---- | ------- | ------- |
| `--input <recorded.json>` | fixture | **`synth` / `simulate`.** Saved recording path |
| `--lifetime <secs>` | `2592000` (30d) | Context-rule lifetime |
| `--spend-window <secs>` | `86400` | Spend-cap window |
| `--cap-multiplier <number>` | `1.1` | Cap = gross outflow × this |
| `--frequency-window <secs>` | `86400` | Frequency window |
| `--frequency-max <count>` | `5` | Max calls in window |
| `--constrain-arguments` | off | Enforce swap-path token set (deny vs flag) |

## `record` flags

| Flag | Default | Meaning |
| ---- | ------- | ------- |
| `<txHash>…` | required unless simulating | 64-hex hashes |
| `--account <G…\|C…>` | first tx source | Subject for flows (warns if assumed) |
| `--from-simulation <file>` | — | Saved simulateTransaction doc |
| `--network <name>` | `testnet` | `testnet` \| `mainnet` \| `futurenet` (RPC endpoint for **recording**) |
| `--rpc-url <url>` | network default | Override RPC |

## `verify` / `install` flags (summary)

- `verify`: `--context-rule` + (`--on-chain-snapshot` **or** `--smart-account`),
  optional `--frequency-policy` / `--spending-limit-policy` / `--network`.
- `install`: `--smart-account`, `--context-rule`, `--frequency-policy`,
  `--spending-limit-policy`, `--signer`, `--network testnet`, optional
  `--dry-run` / `--only`.
