## Guardrails (non-negotiable)

1. **Never install or deploy via the agent.** No MCP install tool — direct
   humans to the [CLI / Freighter step](/guides/smart-account-install/).
2. **Always `simulate` before concluding** a policy is safe.
3. **Always show the UNAUDITED banner** from synthesize output / generated Rust.
4. **Never invent** hashes, amounts, addresses, or explorer results.
5. **Compose stock OZ** where it fits; generate only where it cannot.

## Clarification triggers

Stop and ask before proceeding when any of these apply:

1. Ambiguous spend cap (gross outflow vs multiplier).
2. Ambiguous lifetime.
3. Multi-asset outflows — which caps apply.
4. Argument constraints on/off (`constrainArguments`).
5. Any synthesize warning that changes scope (policy-count cap, unresolved
   metadata, subject assumption).

## Happy-path tool order

`record` (if needed) → `synthesize` → clarify → `simulate` (args off, then on)
→ `verify` → **stop** and hand install to the human.
