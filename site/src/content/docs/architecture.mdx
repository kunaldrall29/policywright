## Stages

### 1. Recording (`src/sources/`)

Produces a `RecordedTx`: hash/network, ordered `ScopedCall`s, and `AssetFlow`s.

- **`fixture.ts`** — offline Blend→Soroswap fixture for demo/CI.
- **`rpc.ts`** — live `getTransaction` by hash(es), SEP-41 events, SAC metadata.
- **`simulation.ts`** — saved `simulateTransaction` exchange.
- **`recorded.ts`** — reload a saved recording.

Typed failures: `BAD_INPUT` / `TX_NOT_FOUND` / `NETWORK` / `DECODE_FAILED`
([src/sources/errors.ts](https://github.com/kunal-drall/policywright/blob/main/src/sources/errors.ts)).

### 2. Synthesis (`src/synthesizer.ts`)

Exact `(contract, fn)` scope, gross-outflow spend caps, inflow-only assets get
no cap, always-on frequency limit, config-gated argument scope. Compose stock
OZ `spending_limit` when a direct transfer was authorized; generate
`FrequencyLimitPolicy` only when no stock policy fits — see
[compose-first](/concepts/compose-first/).

### 3. Emission (`src/emitter.ts`, `src/rust-policy.ts`)

`spec.json`, `context-rule.json`, `summary.txt`, and stamped
`FrequencyLimitPolicy.rs` (byte-locked to
`contracts/frequency-limit-policy` at default config).

<UnauditedBanner />

### 4. Simulation (`src/simulate.ts`)

Fixed-order checks: scope → lifetime → argument (enforced or advisory) →
spend → frequency. See [Dry-run & argument scope](/guides/argument-scope/).

### 5. Verify (`src/verify/`)

Structural diff of emitted context rules vs on-chain snapshot or live
`get_context_rule` fetch — **not** the offline demo self-check.

### 6. Agent layer (shipped)

stdio MCP with **exactly four tools** — no install tool —
[MCP tools](/reference/mcp-tools/). Claude skill loads from
`skills/policywright/` — [Claude skill](/reference/claude-skill/).

### 7. Install (CLI only, testnet)

[`docs/smart-account-install.md`](https://github.com/kunal-drall/policywright/blob/main/docs/smart-account-install.md):
`account:create` → `install` → live `verify`. Signing hierarchy:

1. **Preferred:** Freighter via `stellar-wallets-kit` `signAuthEntry`.
2. **Fallback (labeled):** local ed25519 from `.env` — CLI prints
   `signing: local-signer-fallback` and never claims Freighter signed.

## Design choices

- **`bigint` for amounts**; explicit `now` for deterministic synthesis.
- **Offline-first** fixtures for CI; live RPC opt-in.
- **Agents never install** — human-signed CLI/wallet only.
