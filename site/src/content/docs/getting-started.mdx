Everything on this page runs today against
[the repository](https://github.com/kunal-drall/policywright) and — except for
`record` — needs no network access.

## Prerequisites

- Node.js ≥ 22 (declared in
  [package.json `engines`](https://github.com/kunal-drall/policywright/blob/main/package.json))
- npm

## Install

```bash
git clone https://github.com/kunal-drall/policywright.git
cd policywright
npm ci
```

## Run the demo

```bash
npm run demo
```

The demo records the committed fixture, synthesizes the spec, emits the
artefacts to `out/`, and runs the dry-run scenarios — asserting each behaves as
expected. It exits non-zero if any scenario deviates, so it doubles as a smoke
test ([src/demo.ts](https://github.com/kunal-drall/policywright/blob/main/src/demo.ts)).

## Synthesize and simulate directly

```bash
# Synthesize a spec from the fixture; print the summary + spec.json
npm run cli -- synth

# Run the dry-run scenarios against the fixture's spec
npm run cli -- simulate

# Override synthesis knobs (anything omitted keeps its default)
npm run cli -- synth --lifetime 604800 --cap-multiplier 1.25
npm run cli -- simulate --constrain-arguments
```

With `--constrain-arguments`, the unobserved-route scenario (a swap routed
through a token the recording never touched) is **denied** instead of flagged.
All flags and defaults are listed in the [CLI reference](/reference/cli/).

## Record a live transaction

```bash
npm run record -- <txHash> [--network testnet|mainnet|futurenet] [--rpc-url <url>]
```

Given a transaction hash within the RPC node's retention window, `record`
fetches it via Soroban RPC `getTransaction`, decodes the `InvokeContract` calls
and SEP-41 transfer events into a `RecordedTx`, resolves each token's
symbol/decimals from its SAC metadata (with an explicit `resolved: false`
fallback when that is not possible), and prints the recording as JSON
([src/sources/rpc.ts](https://github.com/kunal-drall/policywright/blob/main/src/sources/rpc.ts)).

- `--network` defaults to `testnet`; each network has a default public RPC
  endpoint.
- `--rpc-url` overrides the endpoint, including a node you run yourself.
- Not-found, failed-on-chain, wrong-network, and decode failures return clear,
  actionable errors instead of empty output.

The live `record` path is optional: the demo and the test suite never use the
network.

## The generated Rust policy

The demo also writes `out/FrequencyLimitPolicy.rs`, an illustrative custom
policy implementing OpenZeppelin's real `Policy` trait — the same source as the
compiled-and-tested crate at
[contracts/frequency-limit-policy](https://github.com/kunal-drall/policywright/tree/main/contracts/frequency-limit-policy)
(25 Rust tests against `stellar-accounts` v0.7.2). Every generated Rust file is
stamped with this header
([src/rust-policy.ts](https://github.com/kunal-drall/policywright/blob/main/src/rust-policy.ts)):

```rust title="out/FrequencyLimitPolicy.rs (generated — header excerpt)"
// =============================================================================
//  ILLUSTRATIVE / UNAUDITED — NOT DEPLOY-READY
//
//  Generated contracts are illustrative and unaudited — not for production
//  deployment until the Audit Bank audit.
//
//  This file was generated by policywright as a *starting point* for a custom
//  OpenZeppelin Stellar smart-account policy. It compiles and its unit tests
//  run against the real OZ `Policy` trait (stellar-accounts v0.7.2), and
//  policywright deploys instances to TESTNET only. It has NOT been audited
//  and MUST NOT be deployed to mainnet or used to guard real value.
// =============================================================================
```
