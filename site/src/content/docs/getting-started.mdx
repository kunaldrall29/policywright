Everything on this page runs today against
[the repository](https://github.com/kunal-drall/policywright). The offline demo
needs no network; live `record` and testnet install are opt-in.

## Prerequisites

- Node.js ≥ 22 (declared in
  [package.json `engines`](https://github.com/kunal-drall/policywright/blob/main/package.json))
- npm

## Install

```bash
git clone https://github.com/kunal-drall/policywright.git
cd policywright
npm ci
```

## Run the demo

```bash
npm run demo
```

Records the committed fixture, synthesizes, emits to `out/`, and asserts dry-run
scenarios ([src/demo.ts](https://github.com/kunal-drall/policywright/blob/main/src/demo.ts)).
Committed artefacts:
[examples/](https://github.com/kunal-drall/policywright/tree/main/examples).

Live (real testnet) artefacts:
[examples/live/](https://github.com/kunal-drall/policywright/tree/main/examples/live)
— see [Agent yield operations](/use-cases/agent-yield-operations/).

## Synthesize and simulate

```bash
npm run cli -- synth
npm run cli -- simulate
npm run cli -- simulate --constrain-arguments
npm run cli -- synth --input examples/live/recorded-claim-swap.json
```

With `--constrain-arguments`, an unobserved swap route is **denied** instead of
flagged — [argument scope](/guides/argument-scope/).

## Record a live transaction

```bash
npm run record -- <txHash> [--network testnet|mainnet|futurenet] [--rpc-url <url>]
```

`--network` selects the RPC endpoint for **recording** only (default
`testnet`). Deploy/install remain **testnet-only** —
[Smart-account install](/guides/smart-account-install/).

## Agent tools

```bash
npm run mcp   # stdio — four tools; no install
```

See [MCP tools](/reference/mcp-tools/) and [Claude skill](/reference/claude-skill/).
