Policywright generates artefacts that, once installed, run as authorization
logic over user funds. This page separates what is **in the code today** from
what is **Planned** (T3 Audit Bank).

## Protections today

- **No key custody in the synthesis / MCP path.** MCP and the record→synthesize→simulate→verify
  pipeline never ask for or use a secret
  ([`src/mcp/`](https://github.com/kunal-drall/policywright/tree/main/src/mcp)).
- **Install is testnet-only and human-signed.** CLI `account:create` /
  `install` refuse non-testnet networks; Freighter preferred; local-signer
  fallback is **labeled**
  ([docs/smart-account-install.md](https://github.com/kunal-drall/policywright/blob/main/docs/smart-account-install.md)).
  The opt-in deploy script
  ([scripts/deploy-testnet.sh](https://github.com/kunal-drall/policywright/blob/main/scripts/deploy-testnet.sh))
  likewise refuses non-testnet.
- **Deny-case verification.** Dry-run harness with auto-generated deny/flag
  cases ([src/simulate.ts](https://github.com/kunal-drall/policywright/blob/main/src/simulate.ts)).
- **Unaudited output is stamped.** Every generated Rust file carries
  `ILLUSTRATIVE / UNAUDITED — NOT DEPLOY-READY`
  ([src/rust-policy.ts](https://github.com/kunal-drall/policywright/blob/main/src/rust-policy.ts)).
- **Storage segregation.** Generated policy keys state by
  `(smart_account, context_rule_id)`.
- **Defensive input handling.** Typed `RecorderError` / MCP error codes.
- **Agents cannot install via MCP.** Exactly four tools; no install tool —
  [MCP tools](/reference/mcp-tools/).

## Threat model

| Threat | Mitigation today | Planned audit focus (T3) |
| ------ | ---------------- | ------------------------ |
| Malicious / malformed input | Defensive decode + typed errors | Adversarial corpus |
| Over-broad scope inference | Exact `(contract, fn)`; gross-outflow caps | Review of every inference rule |
| Storage collisions | `(smart_account, context_rule_id)` keys | Verify generated storage patterns |
| Policy bypass | Fixed-order dry-run + deny cases | Bypass hunting |
| Incorrect lifecycle | Real OZ `Policy` trait, unit-tested | Conformance review |

## Audit commitment

**A third-party audit of the synthesizer and generated policy templates via the
SCF Audit Bank at Tranche 3** — target 30 Nov 2026 on the
[Roadmap](/roadmap/). That audit has **not** happened. Until it has, every
generated contract remains illustrative and unaudited, and this site carries
the banner above on pages that show generated Rust.
